# Python Practice & Problem Solving 🐍

A dedicated repository containing hands-on implementations, logic-building exercises, and problem sets in **Python**. This repository tracks my practical journey with core Python concepts, data handling, and foundational algorithmic problem-solving.

---

## 📌 Topics Covered

- **Python Fundamentals:** Data types, type casting, input/output formatting, and operators
- **Control Structures:** Conditional statements (`if-elif-else`), loops (`for`, `while`), and loop control (`break`, `continue`, `pass`)
- **Data Collections:** 
  - Lists, Tuples, Sets, and Dictionaries
  - List and Dictionary Comprehensions
  - Slicing, indexing, and built-in collection methods
- **Functions & Modules:** User-defined functions, `*args` and `**kwargs`, Lambda functions, and built-in modules (`math`, `random`, `datetime`)
- **String Manipulation:** String formatting (f-strings), regex patterns, and string parsing methods
- **File Handling & Exception Handling:** `try-except-finally` blocks, custom exceptions, and reading/writing files
- **Object-Oriented Programming (OOPs):** Classes, objects, constructors (`__init__`), inheritance, and encapsulation
- **Algorithmic Practice:** Basic math problems, number series, matrix manipulations, and search/sort operations
